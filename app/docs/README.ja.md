# SIMCom Serial AT Console

> [English](README.en.md) · [Español](README.es.md) · [Português](README.pt.md) · [Italiano](README.it.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Русский](README.ru.md) · [中文](README.zh.md) · **日本語** · [한국어](README.ko.md)

ブラウザだけで動作する **SIMCom** セルラーモジュール用の **AT コマンド**コンソールです。**Web Serial API** でシリアルポート経由でモジュールと通信し（インストール不要）、ハードウェアなしで一通り試せる**仮想モード**（内蔵エミュレータ）を備えています。

**A76xx / A7672SA** ファミリ向けに作られ、最も一般的な操作——ネットワーク、データ、GNSS、SMS、メール、電話帳、音声通話、TLS、ファイルシステム、ハードウェア、ジャミング検出など——のためのビジュアルウィザード（*wizards*）に加え、任意の AT コマンドを手動で送れる素のコンソールも用意しています。

> コマンドリファレンス：*A76XX Series AT Command Manual*（V2.04）。

## 機能

- **100% ブラウザ内**、バックエンドも依存もなし。`index.html` を開くだけ。
- USB/UART でモジュールと通信する **Web Serial API**。
- **仮想モード**：数十種類のコマンド（ネットワーク、データ、GNSS、SMS、メール、電話帳、音声、TLS、FS、ハードウェア、ジャミング…）に応答する内蔵 AT エミュレータ。基板なしで開発・デモが可能。
- **素のコンソール**：履歴、自動スクロール、タイムスタンプ、任意のエコー付きで任意の AT コマンドを送信。
- サイドバーにグループ別に整理された**クイックコマンド**。
- フォーム、ライブ表示、地図、SVG チャート、URC 解析を備えた、20 以上の機能領域の**ビジュアルウィザード**。
- 連鎖ステップ、遅延、データ送信、制御文字（`Ctrl-Z`、`ESC`）に対応する**マクロ**。
- **10 言語**（en, es, pt, it, fr, de, ru, zh, ja, ko）。
- **ライト / ダークテーマ**。
- マウスで**サイズ変更できるパネル**（幅と高さ）、ダブルクリックでリセット、ウィザードの**最大化**モード。

## 要件

- Web Serial API 対応の **Chromium** 系ブラウザ：**Chrome**、**Edge**、**Opera**（デスクトップ）。
  - Firefox と Safari は現在 Web Serial に**非対応**です。
- ハードウェアに接続するには、モジュールが OS から見える**シリアルポート**（USB-CDC または UART–USB アダプタ）を公開している必要があります。
- Linux では通常、デバイスへの権限が必要です（例：`dialout` グループへの所属）。

コンソールの利用に Node.js は不要です。Node は[コンパニオンライブラリ](#コンパニオンライブラリsimcom-at-parser)とそのテストにのみ使います。

## クイックスタート

1. プロジェクトをダウンロード／クローンします。
2. Chrome または Edge で **`index.html`** を開きます。
   - ローカルファイル（`file://`）として開いても、静的サーバーで配信しても動作します。
   - 配信したい場合：
     ```bash
     # Python による簡単な方法

     # その後 http://localhost:8080 を開く
     ```
3. 右上で言語とテーマを選びます。
4. ハードウェアなしで試すには **Virtual** を有効にします（後述）。実機の場合はシリアルパラメータを設定して **Connect** をクリックします。

## 仮想モード（ハードウェアなし）

上部バーの **Virtual** トグルを有効にして **Connect** をクリックします。コンソールは **AT エミュレータ**に接続し、モジュール（既定では *A7672SA-FASE*）をシミュレートして、非同期 **URC** を含め実機ファームウェアのようにコマンドへ応答します：

- モジュール、SIM、ネットワーク、信号の情報。
- データセッションの開閉と IP。
- Sky View と地図のための NMEA フレーム（`GSV`/`GGA`）付き GNSS。
- SMS（プリロード受信箱、`>` プロンプトで送信）。
- バイト長による証明書ダウンロード（`CCERTDOWN`）。
- ハードウェア読み取り（電池、温度、ADC、GPIO）。
- 周期的な `+SJDR:` URC によるジャミング検出。
- メール（SMTP）、件名／本文の完全なプロンプトフロー付き。
- 電話帳（プリロード項目、追加／検索／削除）と音声通話（発信 → 通話中、切断）。

ツールを試したりデモを行うのに推奨される方法です。

## 実機への接続

上部バーでポートのパラメータを設定し **Connect** をクリックします（ブラウザがシリアルデバイスの選択を求めます）：

| パラメータ | 選択肢 |
|-----------|--------|
| **Baud**  | 9600 · 57600 · 115200 · 230400 · 460800 · 921600 |
| **Data**  | 8 · 7 |
| **Stop**  | 1 · 2 |
| **Parity**| None · Even · Odd |
| **EOL**   | CR · CRLF · LF（各コマンドに付加される終端） |

**ステータス**バーにはリンク（online/offline）、ポート、信号、ネットワーク登録、オペレーターが表示されます。

> モジュールの**ボーレート**を変更すると（UART ウィザード → `AT+IPR`）現在のシリアルリンクが切れます：新しい速度で再接続する必要があります。

## インターフェース

画面は 3 つのゾーンに分かれ、すべて**サイズ変更可能**です：

```
┌──────────┬───────────────────┬───────────────────────────┐
│ サイドバー│  ウィザード(wiz)   │  AT コンソール             │
│ （グループ）│ （メニューパネル） │  （ログ + コマンド入力）   │
└──────────┴───────────────────┴───────────────────────────┘
```

- **上部バー**：シリアルパラメータ、言語、テーマ、Virtual トグル、Connect ボタン。
- **サイドバー**：グループ化されたクイックコマンド。⚙ アイコン付きの各グループはその**ウィザード**を開きます。
- **ウィザード**：選んだメニューで開く中央パネル。**最大化**（⛶）と**閉じる**（✕）ボタンを備えます。
- **コンソール**：セッションログ（**TIME**、**SHOW ECHO**、**AUTO-SCROLL** トグル付き）、AT コマンド入力、**マクロ**送信。

### サイズ変更可能なパネル

- **サイドバー │ ウィザード** の仕切りをドラッグしてサイドバーの幅を変えます。
- **ウィザード │ コンソール** の仕切りをドラッグしてウィザードの幅を変えます（画面が狭くパネルが縦積みのときは**高さ**）。
- いずれかの仕切りを**ダブルクリック**すると、そのパネルが既定サイズに戻ります。
- ウィザードを**最大化**すると、パネル + コンソールの幅に広がります（コンソールは下、初期は **60/40** 比率）。仕切りは引き続き機能します。

### マクロと制御文字

マクロは複数コマンドを連結します。対応：

| トークン | 動作 |
|---------|------|
| `@delay` | 待機（ステップ間の設定可能な遅延） |
| `>data`  | `>` プロンプトの後に `data` を送信 |
| `^Z`     | `Ctrl-Z`（SMS / ペイロードの終了） |
| `^[`     | `ESC`（キャンセル） |

各ウィザードには**「実行せずエディタに読み込む」**トグルもあり、送信前にコマンドを確認できます。

## ウィザード（wizards）

サイドバーの各グループはウィザードを開けます。プロトコル系 4 つ（TCP/UDP、HTTP、FTP、MQTT）は汎用フォームを使い、残りは専用パネルです。

| ウィザード | 機能 | 主な AT コマンド |
|-----------|------|------------------|
| **Basics** | モジュール情報（型番、リビジョン、IMEI、SIM、信号）、エコー、エラーレベル `CMEE`、**Power/CFUN**（Full/Min/RF off/Reset）。 | `SIMCOMATI`、`CPIN?`、`CSQ`、`ATE`、`CMEE`、`CFUN` |
| **SIM** | ICCID/IMSI/SPN、PIN 解除、ロックと PIN 変更。 | `CICCID`、`CIMI`、`CSPN?`、`CPIN`、`CLCK`、`CPWD` |
| **Network / signal** | オペレーター、信号（dBm）、登録、技術、PS attach。**ネットワークモード**選択（読み取りと対応モード照会付き）。 | `COPS?`、`CSQ`、`CEREG?`、`CGATT?`、`CNMP` |
| **Data** | データセッション状態と IP、セッションの開閉、APN（読み取り／設定）。 | `NETOPEN?`、`IPADDR`、`NETCLOSE`、`CGDCONT`、`CGATT?` |
| **TCP / UDP / Ping** | ソケットと ping のフォーム。 | `CIPOPEN`、`CIPSEND`、`CPING`、… |
| **HTTP** | HTTP(S) リクエストフォーム。 | `HTTPINIT`、`HTTPPARA`、`HTTPACTION`、… |
| **FTP** | FTP(S) 転送フォーム。 | `CFTPSxxx` … |
| **MQTT** | MQTT(S) 接続・パブリッシュフォーム。 | `CMQTTxxx` … |
| **File System** | モジュールのファイルブラウザ（一覧、移動、削除）。 | `CFSGFRS`、`CFSWFILE`、`CFSDFILE`、… |
| **GNSS** | 電源/モード、Cold/Warm/Hot 起動、フィックス（lat/lon/alt/HDOP/UTC）、OSM 地図、極座標 **Sky View** SVG、衛星信号バー（NMEA `GSV`）。 | `CGNSSPWR`、`CGPSCOLD/WARM/HOT`、`CGNSSINFO`、`CGNSSTST` |
| **LBS** | 基地局による測位 + 地図。 | `CLBS` |
| **SMS** | 作成/送信（`>` プロンプト + `Ctrl-Z`）、解析済み受信箱と削除。 | `CMGS`、`CMGL`、`CMGD` |
| **TLS / Cert** | 証明書の一覧/削除、**PEM ダウンロード**（`CCERTDOWN` バイト長指定）、SSL コンテキスト設定（バージョン、authmode、CA）。 | `CCERTLIST`、`CCERTDOWN`、`CCERTDELE`、`CSSLCFG` |
| **Time / diag** | 手動時計（カレンダー + タイムゾーン）、自動タイムゾーン、NTP、DNS 解決。 | `CCLK`、`CTZU`、`CNTP`、`CDNSGIP` |
| **Serial / UART** | ボーレート、フレーミング（`ICF`、例 8N1=`2,2`）、フロー制御、スリープ、CMUX（状態読み取り付き）。 | `IPR`、`ICF`、`IFC`、`CSCLK`、`CMUX` |
| **Hardware** | 電池・温度・ADC の SVG チャート、GPIO（IN/OUT、LOW/HIGH）、デュアルノブスライダーの電圧アラーム。 | `CBC`、`CPMUTEMP`、`CADC`、`CGDRT`、`CGSETV`、`CGGETV`、`CVALARM` |
| **Wi-Fi scan** | AP スキャン（BSSID、チャネル、信号）。 | `CWSTASCAN` |
| **Jamming** | 検出の有効化、URC（`+SJDR:`）によるライブ表示、設定（周期、min RxLev、min チャネル、変化時 URC）。 | `SJDR`、`SJDCFG` |
| **Email** | SMTP(S)：サーバー、認証、作成（From/To/件名/本文）、結果 URC 付き**送信**。SMTP 送信のみ（POP3/IMAP なし）。 | `CSMTPSSRV`、`CSMTPSAUTH`、`CSMTPSFROM`、`CSMTPSRCPT`、`CSMTPSSUB`、`CSMTPSBODY`、`CSMTPSSEND` |
| **電話帳** | ストレージ（SM/ME/DC/RC/MC/FD）と使用/合計、連絡先の一覧/追加/削除、検索、自局番号。 | `CPBS`、`CPBR`、`CPBW`、`CPBF`、`CNUM` |
| **音声通話** | ライブ通話状態（待機/発信/着信/通話中）、発信/応答/切断、DTMF キーパッド、発信者番号トグル。 | `ATD`、`ATA`、`CHUP`、`CLCC`、`CLIP`、`VTS` |

## アーキテクチャ

**国際化（`i18n.js` + `lang/*.js`）。** 表示テキストはすべて**キー**です。各言語は `registerLang(code, name, dict)` で登録し、UI は `t('キー')` で解決します。`data-i18n` を持つ要素は自動翻訳され、ウィザードは描画時に `t()` を使い、言語切替で再描画されます。

**シリアルトランスポート（`serial.js`）。** Web Serial API を *framer*（ストリームから行を構築）付きのトランスポートでラップし、**分類器**が最終応答（`OK`/`ERROR`）、データ、非要求の **URC** を区別します。*VirtualPort* は同じインターフェースを公開しつつ、物理ポートの代わりに **AT エミュレータ**を差し込みます。

**AT エミュレータ（仮想モード）。** 状態（SIM、ネットワーク、データ、証明書、GPIO、GNSS、ジャミング、SMTP、電話帳、通話…）を保持し、各コマンドに実機ファームウェアのように応答します。プロンプト（`>`）、バイト長による確認（証明書、メール）、タイミング制御の URC 発行（NMEA、ジャミング、通話結果）を含みます。

**ウィザードシステム（`data.js` + `app.js`）。** 各クイックコマンドグループは `wiz:'id'` を宣言できます。開くと中央パネルがマウントされ、その `render(host)` 関数（または汎用フォーム）が実行されます。主要な仕組み：

- `UI.sendCollect(cmd, {timeout})` → `OK`/`ERROR` まで行を集める Promise。
- `UI.tap` → 行オブザーバ（ライブ URC 用、例：NMEA、`+SJDR:`、`RING`）。
- `wizCleanup` → アクティブウィザードの後始末（タイマー/tap の停止）。クローズや言語切替時に実行。

## コンソールの拡張

**クイックコマンドの追加。** `js/data.js` の該当する `QUICK` グループ内に、項目 `['i18nキー', "AT+コマンド"]` を追加します（パラメータが必要なら末尾に `1`）。テキストキーを 10 個の `lang/` ファイルすべてに追加します。

**言語の追加。** `registerLang('xx', '名称', { ...すべてのキー... })` を呼ぶ `lang/xx.js` を作成します。`en.js` と同じキーセットを網羅する必要があります。

**ウィザードの追加。** `data.js` で：グループに `wiz:'myId'` を設定し、`{ id:'myId', title:'...', render: (host) => renderMyId(host) }` を登録します。`app.js` で：`UI.sendCollect`、`t()`、（必要なら）`UI.tap`/`wizCleanup` を使って `renderMyId(host)` を記述します。仮想モードでは、`serial.js` のエミュレータにそのコマンドのハンドラを追加します。

> 変更時の推奨：構文の検証（すべての JS を連結して `node --check`）、10 言語間の i18n キーの整合性確認、CSS の波括弧バランス確認、ライブラリのテスト実行。

## コンパニオンライブラリ：`simcom-at-parser`

リポジトリには **`simcom-at-parser`**（v0.1.0）も含まれます。これは SIMCom A76xx/A7672SA モジュールの AT 応答を解析する **Node.js** ライブラリ（ESM、async）で、トランスポート、*framer*、分類器、*modem*、パーサー、サービス層（TCP、HTTP(S)、MQTT(S)、FTP(S)、TLS、GNSS、SMS、FOTA…）を備え、テスト用エミュレータも持ちます。

```bash
npm test          # 約 80 テスト
npm run example   # 基本例
```

- **Node** ≥ 18。
- Web コンソールの AT エミュレータはライブラリのものと同じ思想を共有します。

## 実機に関する注意

挙動の一部はモジュールや SIM/ネットワークに依存します。仮想モードから実機へ移るときは留意してください：

- **GNSS**：ファームウェアによっては `GSV` フレームが AT ポートとは別の NMEA ポートから出力されます。
- **LBS / NETOPEN**：登録済み SIM、有効な PDP/APN コンテキスト、利用可能なネットワークが必要です。
- **ADC**（`CADC?`）：生値はボルトではありません。スケーリングが必要です。
- **Baud / CMUX / CFUN-reset**：シリアルセッションを変更・切断します。再接続が必要です。
- **TLS**（`CCERTDOWN`）：宣言した長さは送信する PEM バイトと**正確に**一致する必要があります。
- **Jamming**：`mnl`（min RxLev）は GSM のみ。周期的な URC レポートには `period > 0` と `detecstat = 1` を設定します。
- **Email**：有効なデータセッション（APN/PDP）が必要です。SMTPS では正しい CA 証明書を読み込み、SSL コンテキストを設定してください（**TLS/Cert** メニュー）。多くのプロバイダ（Gmail）は**アプリパスワード**を要求します。
- **音声通話**：音声サポート/コーデックの有効化が必要です。一部の A76xx 派生は *data-only* で `ATD;` を拒否します。着信の発信者番号はネットワークが提供し `CLIP=1` が有効な場合のみ表示されます。

## 既知の制限

- チャット内プレビューは外部リソースを読み込みません：ローカルの `index.html` を使ってください。
- Web Serial には安全なコンテキスト（`https://`、`localhost`、`file://`）が必要です。
- 本ツールは**診断/開発**用です。複数のコマンドがモジュールの状態（ネットワーク、証明書、NVRAM、ボーレート）を変更します。本番ハードウェアでは慎重に使用してください。
